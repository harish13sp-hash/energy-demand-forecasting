# Energy Demand Forecasting & Consumption Analytics

## Project Overview

This project analyzes hourly energy consumption and generation data and forecasts energy demand using Python, SQL, Machine Learning, and Power BI.

## Dataset

* Period: January 2024 – May 2025
* Total Records: 12,385 hourly records

## Tools & Technologies

* Python (Pandas, Scikit-learn)
* SQL
* Power BI
* Excel

## Project Workflow

1. Cleaned and validated the energy dataset using Python.
2. Performed exploratory data analysis to identify energy consumption patterns.
3. Used SQL queries to summarize and analyze energy data.
4. Built a Random Forest Regression model to forecast energy demand.
5. Created a Power BI dashboard to visualize consumption, generation, and forecast results.

## Model Evaluation

* MAE: 66.24 MW
* RMSE: 79.24 MW
* MAPE: 38.50%
